I'm interested in **embodiment-agnostic task representation**: extracting task structure from human demonstration video that transfers to agents with fundamentally different physical forms.

### 🔭 Currently working on
**[taskcraft](https://github.com/Akileox/taskcraft)** — a self-directed research project using Minecraft as a low-cost, controllable pilot for cross-embodiment imitation via latent world models. Position paper and a technical blog series (VAE → World Models → Dreamer → MuZero → Genie → R3M → VIP → ...) at [akileox.github.io](https://akileox.github.io).
